# 六边形Boss与双层血条

420秒登场一次，调试控制台 `boss hex`；旧方形Boss用 `boss` 或 `boss square`。画面不显示Boss名字。

- 六条边各375000生命（25000×15），红绿蓝循环独立配色。颜色与边血量一同保留到破坏；不是一个统一Boss色。命中点映射到最近边，仅该边扣血，不溢出到其他边。
- 每条边只接受克制该边颜色的弱点伤害；超暴击沿用强制弱点规则。其他彩色攻击显示“抵抗”。无色及灵魂伤害按5%结算。不能被处决或普通强制秒杀绕过拆边。
- 破边后剩余边立即回满，顶点在0.75秒内平滑重连，碎边外飞淡出；剩两条边时死亡，共需破坏四条边。新连接继承相邻存活边的颜色和血量。
- 每次破边使当时场上普通六边形加速60%、无敌5秒，批量绘制旋转护盾外框；刷新时长，不叠加倍率，之后刷出的六边形不自动获得此效果。
- 基础移速36、自转0.25弧度/秒。失去k条边后移速36＋24k＋3.5k²，自转0.25＋0.18k＋0.12k²。
- 冲刺冷却15秒，前摇1.4秒，双轨与箭头提示锁定方向；冲刺2.2秒，提高速度、自转和惯性，不追踪改向。沿途撞死普通小怪，尊重5秒无敌状态。Boss免疫普通推拉，受伤反击的强制击退例外保留。
- 每条边外侧有独立、对应颜色的小血条和血量百分比。前层即时扣血，后层灰紫色延迟0.18秒后缓慢追赶，填充有刻纹与明暗。旧方形Boss也使用同一双层纹理血条。
- 存档保留剩余边颜色/血量、当前顶点与重连进度、冲刺状态；已击败标记独立于方形Boss，继续不会重复奖励。

普通刷怪时间线及无尽模式见根目录《刷怪浓度.md》。测试：`tests/hex_boss_test.tscn`；可加 `-- --preview`、`-- --preview --broken` 输出正常/破边截图。Boss程序化美术是待用户验收稿。
