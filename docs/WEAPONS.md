# 武器与被动兼容 · v0.3.0 测试版

开局基础弹，第一件武器成为主武器。之后获得武器保留当前主武器，并进入已拥有武器选择页；暂停页也可切换。主武器决定动作、倍率和攻速，其他武器只提供以下被动。武器不重复获取。飞出攻击保存取得时的形态/被动快照，切换不修改旧弹；技能属性仍使用共享 StatBlock。

## 主武器

- 剑：120%伤害，100%攻速，150射程，推进弯月剑气，命中击退。
- 闪电：80%伤害，100%攻速，280射程，瞬发；后续链距为本次射程1/4。基础两次命中，加弹射与穿透；穿透链段半伤、不重复，普通弹射可经其他目标后回击。无目标只有枪口光效。
- 星星：80%伤害，100%攻速，600射程；首次命中五枚各50%伤害短射程星片，不自我分裂。
- 回旋镖：100%伤害，100%攻速，340射程；耗尽穿透/射程后再向外36单位，然后返回；双程每敌各命中一次，最多4秒。
- 炮弹：100%伤害，70%攻速，300射程；弹速为普通弹一半，逐渐减速，碰撞或停下爆炸，不重复计算碰撞直击。溅射技能增加本次爆炸倍率和范围。
- 精灵：100%伤害，100%攻速，450射程；小圆弹带短Line2D弧线，减速后索敌短冲刺，攻击次数1＋穿透，吃召唤物加成。
- 水波：每次判定30%伤害，100%攻速，240射程，基础推进180；同一波最多命中每敌三次，至少间隔0.12秒。柔和推退阻力，无潮湿。
- 镰刀：250%伤害，50%攻速，130范围；0.65秒按慢—快—慢曲线完整旋转一圈，刀刃、Polygon2D轨迹与命中角度同步，每敌一次；没有剑时扫击中心跟随角色，半月刃、柄和复用Polygon2D轨迹。

## 副武器

- 剑：武器伤害×1.2，不另发剑气。
- 镰刀：以主武器有效攻速25%独立扫击，使用250%自身伤害并继承技能，不继承其他武器被动。散弹不重复启动计时。
- 闪电：命中后排队产生50%伤害电链（当前调优起点），继承链段规则。
- 水波：命中追加两段各20%伤害，不再递归触发其他被动。
- 回旋镖：原攻击返回；瞬发闪电沿电链返击，范围攻击通过返程阶段转译。
- 星星：命中分裂五枚各20%伤害星片，最多160射程、0.45秒；不能再次星星分裂，可在事件预算内继承其他副效果。
- 炮弹：额外40%溅射；已有溅射技能时改为「技能倍率＋20个百分点」、范围×1.4，覆盖原技能溅射事件。
- 精灵：射程×1.5，平滑追踪。精灵相关弹最多2秒；活动弹超过100时已有弹与新弹均最多1秒。

剑＋镰刀：选择任意一个为主武器时，改为投出旋转镰刀，采用玩家选择的主武器倍率/攻速。没有另一套副镰刀。其余被动继续在有界管线中生效。

## 射程、队列和性能

统一属性 `range=600`、`range_mult=1`；以上形态射程乘以 `range/600×range_mult`，精灵副效果再乘1.5。射程只改变镰刀大小，其他形态改变可推进/索敌距离。处刑弹射程×3，冷却仍5秒，实体无限穿透、非实体穿透＋2。相机可见边界停止攻击，回旋镖触边返航。自动瞄准仍开启，同时受屏幕和射程限制。

直接命中共享颜色、暴击、元素、遗物、处刑和伤害归因。派生只入FIFO：每物理帧最多256事件、接收8派生，每原始攻击最多128派生，总队列4096；全场派生星片上限32；每渲染帧排队命中工作量上限24（闪电链等原子事件可轻微越过），爆炸保存游标跨帧续算，按原FIFO顺序完成。待处理派生软上限128，主攻击仍使用4096硬上限。超额只拒绝新派生，已发生的直接命中不丢失。

普通弹继续使用实测更快的Godot原生碰撞和对象池，形状独占；可用 `--centralized-projectile-collision` 测试集中网格扫掠实现。范围武器复用72单位敌人网格。怪群分离默认用WorkerThreadPool纯数据快照；`--no-threaded-flock`回退、`--adaptive-flock`比较旧64怪阈值。主线程不等待未完成任务，不在工作线程访问SceneTree。

Boss地面宝箱与「家传神兵」提供三选一；角色专属天赋仅保留接口。八把图标沿用程序绘制，卡片可触控，有悬停放大和点击流光。闪电、水波、镰刀最新美术已获用户同意先继续，后续实战再调。黑洞是独立技能，不再是武器。

## 桌面调试控制台

仅调试版桌面按 `~`（键盘左上角反引号键）打开，Tab 补全，方向键上下翻历史，Enter 执行，Esc 或 `~` 关闭。手机版不创建控制台。正式版启用方式以后由配置文件决定。

- `w 武器ID`：直接获得武器，保留当前主武器；在暂停页「切换主武器」查看和切换。
- `rw 武器ID`：移除已拥有武器；若移除主形态，从其余武器选择后备，全部移除后恢复基础弹。
- 武器 ID：`sword`、`lightning`、`star`、`boomerang`、`cannon`、`sprite`、`wave`、`scythe`。
- `e triangle|square|hex|plane|round 数量 [red|green|blue]`：在玩家周围刷怪，单次最多 500 只。
- `bh 1–4`：解锁黑洞技能至指定阶，并立即释放一次供调试。
- `r 遗物中文名或ID`：直接拾取遗物；支持Tab补全、`r lucifer`、`r michael`，遵守唯一与件数限制。
- `boss`（方形Boss）、`boss hex`（六边形Boss）、`gold 数量`、`xp 数量`、`clear`、`fps`、`help`。

武器发射/挥动与命中音各自使用 `weapon_<id>` / `weapon_hit_<id>` 合成音，不再共用旧 shoot/hit 声。剑和镰刀为不同长度的气流挥砍声，炮弹为低频短爆声，其余使用独立音高与噪声配置。

炮弹＋回旋镖：去程爆炸只触发一次，弹壳向外延伸后返航，返程爆炸采用65%倍率；其他回旋镖双程命中限制仍生效。

调试新增：`origin X`，随机存活敌人启动1秒蓄力源反应；X指定测试元素池伤害。先`e triangle 10`可生成目标。关闭控制台后计时。

剑＋镰刀投掷体更新：判定半径、刀刃和轨迹统一为普通镰刀80%，随有效范围同比变化。

2026-11-02：闪电基础射程280（此前300）；首击倍率80%不变，后续正常链段90%、穿透链段45%，均相对本次闪电伤害；副闪电沿用50%起点，再乘90%链段系数。首击及全部连锁目标仅在可见视野内。所有武器实际推进距离取「属性射程与沿方向到可见边界的距离」较小值；手机按camera.zoom计算，无额外100px攻击余量。属性页显示理论射程，实际受到方向与屏幕边界约束。技能黑洞/源反应不是武器，不套用此边界伤害限制。
