# 武器融合首版

开局仍使用基础弹。第一件武器替换攻击形态；后续武器只提供机制，不叠加自身伤害或射速倍率。获得新武器时可从已拥有武器中选择主形态，之后直到下次融合才可更改。同一种武器一局只能获得一次。

当前四件：剑（120% 半月形宽剑气向前推进、淡出并击退）、闪电（瞬发并弹射）、星星（80% 主弹，命中散出五枚半伤害星片）、回旋镖（340 单位飞出后返回，返回段无限穿透）。剑＋回旋镖让同一道剑气折返，回旋镖为主时在折返点生成剑气；闪电＋星星有链末散射。星星为主时，星星弹自身继承回旋镖折返，无额外回旋镖弹。其余组合通过副效果转译，不能直接套用的返回行为改为闪电返击。

Boss 击杀后打开武器三选一；角色专属天赋奖励位留待内容确定后开放。唯一遗物「武装密钥」在普通商店与幸运宝箱的炬火遗物池中出现，拾取后再提供一次武器三选一。已拥有武器不会重复出现在选项中。

连锁效果通过 `WeaponCombat` 的 FIFO 队列逐物理帧处理，每帧最多处理 256 件、每帧最多接收 8 件派生、每次原始攻击最多派生 128 件、队列最多 4096 件；星片全场同时最多 32 枚。超额派生跳过，直接命中照常结算。所有形态共用颜色、暴击、元素、溅射、处决及伤害统计。未来炮弹、精灵、水波、镰刀、黑洞分别接入爆炸、追踪、附着、斩击、合并阶段。

## 桌面调试控制台

仅调试版桌面按 `~`（键盘左上角反引号键）打开，Tab 补全，方向键上下翻历史，Enter 执行，Esc 或 `~` 关闭。手机版不创建控制台。正式版启用方式以后由配置文件决定。

- `w sword|lightning|star|boomerang`：直接获得武器，然后打开已拥有武器的主形态选择面板。
- `primary sword|lightning|star|boomerang`：切换已拥有的主武器。
- `e triangle|square|hex|plane|round 数量 [red|green|blue]`：在玩家周围刷怪，单次最多 500 只。
- `boss`、`gold 数量`、`xp 数量`、`clear`、`fps`、`help`。
