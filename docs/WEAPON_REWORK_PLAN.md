## 2. 统一射程与回收

- **[complete]** WeaponRuntime维护射程基础值与射程增幅，攻击生成时快照有效射程。初值尽量对齐现有手感，逐武器列出数值供调整。
- **[complete]** 实体弹按实际行进距离消耗预算，射程耗尽可早于寿命移除；保留寿命兜底。射程增幅只改变镰刀攻击大小，不增加其余武器体型/宽度。
- **[complete]** 镰刀射程映射扫击半径；剑气射程影响前进距离；水波影响推进距离。闪电首目标必须在有效射程内，后续每段链最多为本次射程1/4，链次数仍有界；无合法目标仅枪口光效，不画空击电线。
- **[complete]** 相机可见区域外留一段余量回收（PC与手机都用真实camera.zoom）；不要求所有子弹飞满射程。回旋镖遇到射程/屏幕回收边界先向外穿过一小段再返航，超出安全余量则立即返航，返回另设超时兜底。
- **[complete]** 精灵型攻击最多2秒，场上活动弹>100时最多1秒；包括已有弹的剩余寿命收紧，避免只限制新弹而旧弹堆积。普通精灵主形态及继承其追踪的弹都覆盖。
- **[complete]** 五秒处刑射程×3，用户已确认冷却仍5秒；保留实体无限穿透/特殊穿透+2。独立检测射程、寿命、回收边界，不能因无限穿透永不释放。
- **[complete]** 索敌同时受屏幕、射程和攻击形态限制；暂不关闭自瞄/自动攻击，也不新增手动攻击按键，待用户决定。

## 3. 恢复主武器选择并替换副效果

- **[complete]** 首把武器成为主形态；之后获取不自动替换，允许玩家在已拥有武器中主动选择。暂停武器页与拾取流程提供切换入口，手机可触控，不依赖键盘。主形态和切换状态进存档，旧档缺字段时沿用原推导结果。
- **[complete]** 攻击生成时冻结主形态/副效果快照，切换不改变已飞出的弹；移除主武器时才选择合理后备，避免旧优先级覆盖玩家选择。
- **[complete]** 副剑：武器伤害倍率提高20%，暂按乘1.2实现，不额外生成剑气。
- **[complete]** 副镰刀：按原主武器有效攻速25%独立产生斩击，伤害与技能共同结算；该斩击不继承其他武器副效果，不在每颗散弹命中时重复开冷却。不得递归召唤自身。
- **[complete]** 副闪电：命中排队触发闪电链，伤害先沿用现有副闪电倍率作为起点，在射程内且事件预算允许时结算；首轮验收单列其触发频率与实际伤害占比再平衡。
- **[complete]** 副水波：命中后额外两段各20%伤害，使用有界延迟命中事件，不重复触发自身或其他副效果链。
- **[complete]** 副回旋镖：原攻击自身返回，折返点向外延伸一小段；瞬发/范围形态用返击阶段转译，不凭空再生成独立回旋镖。
- **[complete]** 副星星：命中分裂5颗各20%伤害的小弹，短射程；分裂来源标记阻止再次星星分裂，后续可继承的效果按预算白名单执行。
- **[complete]** 副炮弹：额外40%溅射；已有技能溅射时使用“原溅射倍率+20个百分点”、范围×1.4，覆盖原溅射事件，不能两套重复出伤。炮弹主形态自身爆炸与副炮弹增益区分，避免自身又叠副效果。
- **[complete]** 副精灵：射程×1.5并追踪，受本轮2秒/高压1秒寿命限制；非实体形态按目标更新/轨迹规则适配，避免生成无意义附加弹。
- **[complete]** 剑＋镰刀：选其中之一为主武器时改为投出旋转镰刀，替换旧“扫一圈再发剑气”组合。其余已拥有副效果走新的有界管线，不能额外再自动触发一套副镰刀。
- **[complete]** 清除旧专用组合的重复触发路径，覆盖8主形态、56个有方向两武器组合、多武器、取得顺序、切换/移除、旧存档与伤害归因。
