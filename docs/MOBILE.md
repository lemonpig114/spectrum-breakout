# Android 触屏测试

## 当前操作

- 左下区域按下即出现浮动摇杆；手指拖动控制方向与速度，松手后消失。摇杆有 10 px 死区，拖过外环时基座会缓慢跟随手指。
- 另一根手指在战斗区域轻点：切换到下一个颜色。左右横滑：选择上一个或下一个颜色。长按：查看切色轮盘；不选择方向就松开会取消。
- 手机端自动索敌、自动射击，没有左键手动瞄准，也没有额外的战斗按钮。右上角和安卓返回操作均可暂停；切到后台时自动暂停。桌面键鼠操作不变。
- 商店、升级、祭坛、遗物选择等面板沿用触摸模拟鼠标点击；已在手机模式隐藏主要的键盘提示，遗物选择按钮加大。

## 测试顺序

1. 先在电脑端运行 `res://tests/mobile_controls_test.tscn -- --mobile-controls-test`。脚本覆盖摇杆死区、满速、浮动跟随、双指同时操作、轻点、左右滑、长按取消、暂停松手、安卓返回与切后台、禁止触屏手动瞄准。
2. 在 Godot 的运行参数中添加 `--mobile-controls-test`，用鼠标单指体验摇杆出现位置和视觉。电脑鼠标不能真实模拟两根手指的触感；双指逻辑由上述自动化测试验证。
3. 把 `build/spectrum-breakout-android-debug.apk` 复制到 ARM64 安卓手机并安装。测试实际多点触控、摇杆响应、按钮大小、刘海安全区、画面效果及 180 秒后的帧率和发热。手机端验收后再微调死区、半径、跟随速度与画质。

## 导出记录

- Godot 4.4.1 的 Android 34 SDK、构建工具与导出模板已配置；项目开启 ETC2/ASTC 导入。桌面保持 Forward+，安卓使用 Godot 默认的 Mobile 渲染器。
- 本机 `export_presets.cfg` 和 `build/` 已忽略，避免把调试签名文件与将来可能加入的发行签名信息提交到公开仓库。
- 调试 APK 为 ARM64、清单最低 API 21、目标 API 34、固定横屏；所用 Mobile/Vulkan 渲染器实际应在支持 Vulkan 的 Android 9+ 手机上测试。签名由 `apksigner verify` 确认。此包用于实机测试，不是商店发行包。
