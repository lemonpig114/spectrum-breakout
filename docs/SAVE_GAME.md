# 局内存档与主菜单

主流程：启动演出 → 主菜单。五个入口为开始游戏、继续游戏、设置、图鉴、退出。开始游戏进入选角，继续游戏直接恢复存档；没有有效存档时继续按钮变灰。PC与手机使用同一局内存档实现，手机设置额外显示摇杆底座跟随选项。

## 自动保存

- 单局单槽 `user://run_save.dat`，Godot会将其放在本游戏用户数据目录，正式文件不写入工程目录。
- 每10秒保存；完成升级/武器选择、离开商店/祭坛、暂停返回菜单、窗口失焦/关闭及手机切后台时保存。
- 先写临时文件并刷新，再替换正式文件，保留上一份 `.bak`；读取时正式文件无效会尝试备份。
- 开始新的一局后覆盖当前槽；选角中取消返回不会先删掉旧存档。死亡清除正式文件、备份和临时文件。
- 手机被系统直接杀进程时，不保证收到退出通知，最多回到上次成功保存的状态；切后台时会主动保存。

## 恢复内容

- 角色、游戏时间、等级/经验与小数累积、正负金币、当前/最大生命、能量、颜色、位置、相关技能计时。
- 已选技能、重复遗物、全部武器及固定优先级融合，玩家和武器完整属性修改器；包括商店/祭坛消耗造成的永久属性变化。
- 路西法恶魔护盾、无盾补充计时、半心转换余数、生命上限转换基准和累计治疗攻击一并保存；恢复已有属性，不重放转换。
- 护盾、灵魂击杀数、成长计数、短期能量/幸运/骰子/肾上腺素效果，动态属性修饰器会重新连接，能继续随计时变化。
- 商店等级、购买/刷新次数、家传神兵已上架标记、商人和祭坛倒计时及当前NPC；已打开的货架、价格、已售状态、免费刷新和单次治疗状态。
- 未完成的技能选项及重选次数、当前武器三选一候选和后续排队奖励、待领取遗物。
- 已击败Boss标记；活着的Boss恢复血量、位置、颜色、招式进度和主要状态，不能靠继续游戏重复刷同一个Boss奖励。
- 六边形Boss另存独立击败标记、各边血量与颜色、顶点/重连动画、冲刺状态；无尽模式公告已显示标记也保存，继续后不重复弹出。
- 地面经验/金币/宝箱数量和年龄；磁吸中的掉落继续收集，未拾取掉落不会因读档直接计入收益。
- 黑洞当前累计伤害/大小/计时，以及法阵计时/位置和对应增益；随机数状态保留。

普通怪群按当前时间阶段重新生成；飞行子弹、爆炸特效、伤害数字、分身实体和黑洞内旋转攻击不序列化。它们由现有运行时重新生成；已累计的黑洞伤害和角色构筑仍保存。继续时镜头直接对准保存位置，不重新播放开场演出。

属性通过 `StatBlock.save_data/restore_data` 恢复，不重复调用 `Skills.unlock/grant_relic`，避免债券再扣钱、金块再发钱、金苹果再回血、家传神兵再次扣伤害/发武器、骰子再次重掷。

音量、静音、FPS显示与手机摇杆偏好继续使用各自设置文件，与当前局存档独立。

## 开发与验证

存档格式版本为1，使用FileAccess原生Variant存储，仅保存基础类型，不允许反序列化Object。之后若更改属性数据格式，需显式迁移或提高版本，避免默默读错。当前快照保留存档时的属性数值；后续平衡改动不自动重算旧存档中的所有属性。

`tests/save_game_test.tscn` 使用独立测试槽，覆盖磁盘往返/备份、实际重建Main、属性不重复、动态修饰器、商店、Boss、未完成升级和武器奖励、手机后台通知及死亡清档。嵌入其他测试场景的Main不启用真实槽自动存档。

菜单验证：`tests/menu_test.tscn`。截图：`tests/menu_screenshot.tscn -- --mode main --shot res://tests/visual_main_menu_save.png`；手机设置可加 `--mobile-controls-test --mode settings`。
